# Legacy prototype

This directory contains sanitized archival copies of the original console,
JavaFX, SQL dump, and ER-diagram artifacts from before the web modernization.
An embedded JDBC credential and password logging were redacted during the
security review; the legacy business logic is otherwise retained for study.

They are retained for:

- demonstrating the project's evolution during the viva;
- tracing the original JDBC business rules;
- comparing the former schema with the versioned production schema.

The files here are archival and are not compiled or deployed by the modern
application.
